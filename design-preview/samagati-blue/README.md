# Samagati — simple blue concept

Separate second design. Existing green preview and Flutter source unchanged. Existing preview login is preserved, including its styling.

Run `python app.py --port 8097`. Open http://127.0.0.1:8097/mobile.html for a full phone frame with Patient / Doctor / Login switches. All controls inside the phone are interactive.

HTML/CSS/JavaScript frontend, Python standard-library demo API. Demo OTP: 123456. All records, bookings and payments are fictional. No live authentication, hospital API or payment system is connected. Server data resets on restart.
